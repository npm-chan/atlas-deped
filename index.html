Subject Management

Subjects are the school's single academic reference — added and managed here, per School Year, Term, and Grade Level. Select a School Year, Term, and Grade Level, then click + Add Subject to add one. Every subject is tied to a specific School Year + Term + Grade Level, so nothing is mixed across years or terms. When adding or editing a subject, set Schedule Days to "Friday Only" for subjects (e.g. clubs, values formation) that should be excluded from the Monday–Thursday rotation and appear only in Friday's schedule.

Sections

Junior High (Grades 7–10) and Senior High (Grades 11–12) sections are subject-based, with a rotating Subject Teacher per learning area. Senior High sections follow one of three tracks — TechPro (Technical-Professional/TVL electives), ACADS (general Academic-Track/GAS-style electives), or Both (draws electives from each menu) — whose specialized subjects are added on top of the shared Grade 11/12 core subjects. Stand-alone elective subjects not tied to any track can be added as "Elective" type subjects on the Subjects page.

Bulk-Apply a Base Start Time

Each Grade Level has its own class starting time, set individually in the table below. This is just a shortcut: enter a base time and it staggers every grade level by 15 minutes from it (e.g. Grade 7 at the base time, Grade 8 fifteen minutes later, and so on) — you can still fine-tune each grade's time afterward.

Per-Grade-Level Bell Configuration

Every Grade Level has its own configurable class start time, and its own morning break, lunch, and afternoon break — set as minutes after that grade's own start time, plus how long each lasts. Class period length and periods/day are also configurable per level. Defaults are 15 minutes for the Morning (Day) Break, 60 minutes (1 hour) for Lunch, and 15 minutes for the Afternoon Break — all fully editable below.

Schedule Settings

Monday–Thursday are always regular teaching days. Friday is optional. Set a custom duration per subject — subjects left blank use the grade level's default period length above.
Grade 11/12 sections set to "PM Class" start their bell schedule from this clock time instead of the grade's normal start time. A Grade 11/12 section set to "AM Class" is flagged as an AM/PM Shift Conflict if that grade's own Class Start Time (set below) is at or after this boundary — meaning it could never actually meet in the morning.
Enable Friday Schedule
